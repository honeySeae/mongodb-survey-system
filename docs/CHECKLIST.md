# 第一阶段完成清单

> 依据 `docs/REQUIREMENTS.md` 原文整理（括号内为原文出处）。每完成一步更新打勾，并注明对应的提交或文件。
> 图例：`[x]` 已完成　`[ ]` 未完成

## 一、功能（初始用户需求）

### 1. 用户账号（需求一）
- [ ] 注册账号（用户名、密码、注册时间）
- [ ] 登录账号
- [ ] 使用自己的账号创建问卷
- [ ] 查看自己创建的问卷
- [ ] 查看问卷的统计结果
- [ ] 登录后只能看到自己创建的问卷（他人的问卷、统计、答卷不可访问）

### 2. 问卷创建与管理（需求二）
- [ ] 创建问卷：标题、说明、是否允许匿名填写（另含本项目的提交策略设置）
- [ ] 查看自己创建的问卷列表
- [ ] 发布问卷
- [ ] 设置问卷截止时间
- [ ] 关闭问卷
- [ ] 每个问卷有可访问的链接 `/survey/xxxxxx`（前缀由 `PUBLIC_BASE_URL` 配置）
- [ ] 填写问卷的人需要先登录

### 3. 题目（需求三）
- [ ] 一个问卷可包含多个题目
- [ ] 单选题：设置选项、是否必答；必答时填写必须选择
- [ ] 多选题：至少选 N 个、最多选 N 个、必须选 N 个；填写时检查
- [ ] 文本填空：最少/最多字数；填写时检查
- [ ] 数字填空：最小值、最大值、是否必须为整数；填写时检查（如年龄 0~120 整数、手机号整数）
- [ ] 整数答案超出 64 位范围时按校验错误提示（设计文档 6.6）

### 4. 题目跳转（需求四）
- [ ] 根据单选结果跳转
- [ ] 根据多选结果跳转
- [ ] 根据数字填空内容跳转
- [ ] 填写时自动跳到对应题目
- [ ] 跳转规则在问卷中设置，不写死在程序里

### 5. 填写问卷（需求五）
- [ ] 通过问卷链接进入问卷
- [ ] 按顺序回答问题
- [ ] 根据规则跳转
- [ ] 填写不符合要求时提示错误
- [ ] 填写完成后提交
- [ ] 每次填写都被保存
- [ ] 支持多人同时填写
- [ ] 支持匿名填写
- [ ] 支持同一个人填写多次（如果允许）

### 6. 统计结果（需求六）
- [ ] 单选题：每个选项多少人选择、总共多少人回答（同时返回答卷数和去重后的作答人数，设计文档 6.7）
- [ ] 多选题：每个选项被选择多少次
- [ ] 填空题：查看所有填写内容
- [ ] 数字填空：平均值
- [ ] 查看整个问卷的统计
- [ ] 查看某一道题的统计
- [ ] 统计根据已填写的数据自动生成（聚合管道实时计算）

## 二、技术与 MongoDB 设计（项目说明三、四）

- [x] 不把所有数据存在一个集合（users / surveys / responses）
- [x] 谨慎使用冗余设计（设计文档 7.5）
- [ ] 逻辑不写死在代码中（校验、跳转规则存为数据；在第五、六步实现时确认）
- [x] 说明为什么这样设计（设计文档第七节）
